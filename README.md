# MegaWidget International – Excel Analytics & Decision-Support Model

**Advanced Excel | VBA | Macros | Pivot Tables | Pivot Charts | Financial Modelling | What-if Analysis**

## Project Overview

Developed an Excel-based analytics and decision-support solution for **MegaWidget International** as part of MSc Business Analytics coursework. The project combines data preparation, interactive sales reporting, financial modelling and scenario analysis to support business expansion decisions.

The solution was designed to turn operational and sales data into management-focused insights while allowing users to test alternative financial assumptions through an interactive Excel model.

## Business Objectives

- Analyse monthly sales performance across products, years and geographical areas.
- Transform and organise raw operational data for reporting and analysis.
- Build an interactive management dashboard using Pivot Tables, Pivot Charts and slicers.
- Develop a cash-flow forecasting model incorporating key revenue and cost assumptions.
- Use VBA and macros to improve navigation, model interaction and scenario input.
- Evaluate alternative expansion assumptions through what-if analysis.
- Translate analytical outputs into business-focused recommendations.

## Interactive Sales Dashboard

Built an interactive Excel sales dashboard using **Pivot Tables, Pivot Charts and slicers** to analyse monthly sales volumes by product, year and postcode area. Users can dynamically filter the dashboard to investigate changes in product and regional performance.

**Key analytical features:**

- Monthly sales-volume analysis
- Product-level filtering
- Year-based comparison
- Regional/postcode analysis
- Interactive slicers and Pivot Charts
- Management-focused visual reporting

## Cash Flow Forecast & Financial Model

Developed a cash-flow forecasting model incorporating sales revenue, government grants, advertising expenditure, cost of goods sold and loan repayments.

A **VBA-driven user-input interface** allows business assumptions to be changed and recalculated, including:

- Loan amount
- Interest rate
- Loan term
- Profit margin
- Delivery cost
- Government grant assumptions
- Advertising expenditure

The model uses these assumptions to calculate projected monthly cash flow and assess the financial viability of the proposed business plan.

## Scenario & What-if Analysis

Performed what-if analysis to evaluate how changes in business assumptions affect projected cash flow and overall financial viability. Alternative scenarios can be compared against the original model to support evidence-based expansion decisions.

This part of the project demonstrates the use of analytical modelling not only to report historical information, but also to support forward-looking business decisions.

## Data Preparation & Analysis Workflow

The workbook follows an end-to-end analytical workflow:

**Raw Data → Data Cleansing → Data Organisation → Pivot Analysis → Interactive Dashboard → Cash-flow Forecasting → What-if Analysis → Business Recommendation**

This structure demonstrates how raw operational data can be transformed into a decision-support tool for management.
